# Project: My Start Page

This project was built using Kiro IDE.

## Stack
- HTML, CSS, Vanilla JavaScript
- No frameworks, no backend
- Data stored in browser LocalStorage

## Features
- Greeting with live clock and date
- Focus Timer (Pomodoro) with custom duration
- To-Do List with add, edit, done, delete
- Quick Links saved to LocalStorage

## Challenges implemented
1. Light / Dark mode
2. Custom name in greeting
3. Prevent duplicate tasks
4. Sort tasks (bonus)
